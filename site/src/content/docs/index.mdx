nvault is a small secrets proxy. A directory owns the provider config. A
command reads one key. The value does not ride in `argv`.

This site is the human guide and the agent lookup. Reference pages stay
literal. The emoji stay on this page.

## Where the value goes

`exec` maps a key name to an environment variable in the child. The process
table sees the name. It does not see the value.

## The short rules

<CardGrid>
	<Card title="No value flag" icon="warning">
		`set` and `ensure` read stdin or a hidden prompt. A `--value` flag does
		not exist, on purpose.
	</Card>
	<Card title="Names only" icon="list-format">
		`ls` and `search` print names only. Vaultwarden's `bw list items` and
		Proton's `pass-cli item list` do fetch item bodies to produce them, but
		neither adapter prints a value.
	</Card>
	<Card title="No remove" icon="close">
		There is no delete command. `ensure` creates through a path that cannot
		replace an existing key and otherwise leaves it alone.
	</Card>
	<Card title="Original jokes only" icon="star">
		The terminal panels on this page are HTML written here. No third-party
		gif is embedded, hotlinked, or redistributed.
	</Card>
</CardGrid>
