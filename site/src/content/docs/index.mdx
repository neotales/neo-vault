nsvault is a small secrets proxy. A directory owns the provider config. A
command reads one key. The value does not ride in `argv`.

This site is the human guide and the agent lookup. Reference pages stay
literal. The emoji stay on this page.

<CardGrid>
	<Card title="No value flag" icon="warning">
		`set` and `ensure` read stdin or a hidden prompt. A `--value` flag does
		not exist, on purpose.
	</Card>
	<Card title="Names only" icon="list-format">
		`ls` and `search` return names. They do not fetch values.
	</Card>
	<Card title="No remove" icon="close">
		There is no delete command. `ensure` creates when absence is confirmed
		and otherwise leaves the key alone.
	</Card>
	<Card title="Not a meme host" icon="star">
		No third-party gif is embedded here. A hotlinked meme is someone else's
		file, and this page does not need one.
	</Card>
</CardGrid>
